# Installation

## Stable release

To install cluster_validator, run this command in your terminal:

```sh
uv add prevalidate
```

Or if you prefer to use `pip`:

```sh
pip install prevalidate
```

## From source

The source files for cluster_validator can be downloaded from the [Github repo](https://github.com/florence-bockting/prevalidate).

You can either clone the public repository:

```sh
git clone https://github.com/florence-bockting/prevalidate
```

Or download the [tarball](https://github.com/florence-bockting/prevalidate/tarball/main):

```sh
curl -OJL https://github.com/florence-bockting/prevalidate/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd prevalidate
uv sync
```
